# Python packages for training, evaluating and exporting the models in
# scripts/*.py. The app itself does not need any of this — it runs the
# exported ONNX files in ml/ from Node.
#
#   python3 -m venv .venv-train
#   .venv-train/bin/pip install -r requirements-train.txt
#
# The run-*.sh and finish-training.sh scripts expect the environment at
# .venv-train, which .gitignore already leaves out.
#
# Versions here are floors, not the exact set the models were trained with —
# that set only ever lived in the original .venv-train. To record it, run this
# on the machine that has it and commit the result:
#
#   .venv-train/bin/pip freeze > requirements-train.lock.txt
